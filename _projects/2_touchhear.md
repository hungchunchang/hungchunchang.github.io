**[GitHub](https://github.com/hungchunchang/touchhear)**

TouchHear is a learning tool designed for visually impaired students. The system provides real-time audio feedback as the student touches dotted tactile figures, enabling spatial and topographic concept learning through sound.

Built in **Python** with **PyQt6** as the main UI framework, combined with a **FEMTO BOLT RGB-D camera** for real-time hand gesture detection.
